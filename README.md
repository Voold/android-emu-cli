# Android Emulator CLI

Простая интерактивная консольная утилита для управления Android Virtual Devices (AVD) на macOS.

Она позволяет создавать и запускать эмуляторы, сохранять параметры запуска, открывать Chrome DevTools для конкретного WebView и запускать настроенный `mitmproxy` — всё из одного меню.

## Возможности

- просмотр, запуск, настройка и удаление существующих AVD;
- создание устройства из актуального списка профилей и системных образов Android SDK;
- запуск эмулятора с дополнительными флагами и сохранение их по умолчанию;
- запуск эмулятора в отдельном окне Terminal с видимыми логами;
- открытие Chrome DevTools для выбранного запущенного эмулятора и WebView;
- настройка и запуск `mitmproxy` с addon-скриптами и произвольными аргументами;
- управление меню с клавиатуры и понятная обработка ошибок.

## Требования

- macOS;
- Node.js `20.17+`, `22.13+` или `23.5+`;
- Android SDK Command-line Tools;
- команды `adb`, `avdmanager`, `emulator` и `sdkmanager` должны быть доступны в `PATH`;
- Google Chrome — только для функции DevTools;
- `mitmproxy` — только для функции запуска mitm.

Проверьте Android SDK:

```bash
adb version
avdmanager --version
emulator -version
sdkmanager --version
```

Если команды не найдены, установите Android Studio или Android Command-line Tools и добавьте SDK в `PATH`:

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

Добавьте эти строки в `~/.zshrc`, чтобы настройка сохранялась после перезапуска Terminal.

## Быстрый запуск

```bash
git clone https://github.com/Voold/android-emu-cli.git
cd android-emu-cli
npm install
npm start
```

После запуска появится главное меню:

```text
Android Emulator CLI

❯ Мои устройства
  Создать устройство
  Открыть DevTools
  Запустить mitm
  Выход
```

## Глобальная команда

Чтобы запускать утилиту из любой директории:

```bash
cd android-emu-cli
npm link
android-emu
```

Удалить глобальную ссылку:

```bash
npm unlink -g android-emu-cli
```

## Работа с устройствами

В разделе «Мои устройства» можно:

- запустить AVD с сохранёнными параметрами;
- выбрать параметры для разового запуска;
- сохранить выбранные параметры по умолчанию;
- открыть `config.ini` устройства в `$VISUAL` или `$EDITOR`;
- удалить AVD после подтверждения.

Эмулятор открывается в новом Terminal. Пока это окно открыто, процесс эмулятора работает; закрытие окна завершает его.

## Создание устройства

Утилита получает профили через `avdmanager list device`, а системные образы — через `sdkmanager --list`.

Если выбранный образ не установлен, утилита предложит скачать его. Также можно вручную указать ID профиля или package ID системного образа.

## Chrome DevTools

1. Запустите эмулятор.
2. Откройте нужную страницу в Chrome или приложении с WebView.
3. В главном меню выберите «Открыть DevTools».
4. Выберите запущенный AVD и нужную вкладку.

Для WebView приложение должно разрешать удалённую отладку:

```java
WebView.setWebContentsDebuggingEnabled(true);
```

Утилита автоматически находит debug-сокет, создаёт `adb forward` и открывает совместимую с WebView версию Chrome DevTools.

## mitmproxy

Установите mitmproxy:

```bash
brew install mitmproxy
```

Пункт «Запустить mitm» позволяет настроить:

- один или несколько Python addon-скриптов (`-s` для каждого файла);
- порт прослушивания;
- режим `regular`, `upstream`, `transparent` или `socks5`;
- `--ssl-insecure`;
- `--set block_global=false`;
- уровень подробности логов;
- произвольные аргументы командной строки.

Перед запуском отображается итоговая команда. Если порт занят, утилита предложит ближайший свободный и сохранит новое значение.

Настройки сохраняются локально:

```text
~/.android-emu-cli/mitm-config.json
```

## Локальные настройки

Утилита не записывает пользовательские настройки в репозиторий.

```text
~/.android-emu-cli/launch-defaults.json
~/.android-emu-cli/mitm-config.json
```

## Частые проблемы

### Android SDK не найден

Убедитесь, что `adb`, `avdmanager`, `emulator` и `sdkmanager` доступны в `PATH`.

### DevTools не видит WebView

- устройство должно быть запущено и видно в `adb devices`;
- нужная страница должна быть открыта;
- в приложении должен быть включён `WebContentsDebugging`.

### Порт mitmproxy занят

Утилита проверяет порт до запуска и предлагает другой. При необходимости посмотреть владельца порта вручную:

```bash
lsof -nP -iTCP:8080 -sTCP:LISTEN
```

## Ограничения

- запуск процессов в отдельном Terminal реализован только для macOS;
- создание AVD зависит от доступности репозиториев Android SDK;
- `transparent`-режим mitmproxy может потребовать дополнительной системной настройки и прав;
- утилита не устанавливает сертификат mitmproxy на Android автоматически.
